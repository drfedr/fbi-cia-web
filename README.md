# fbi-cia-web

Веб-интерфейс для установки `.cia` файлов на Nintendo 3DS через **FBI → Remote Install → Scan QR Code**.

Показывает список `.cia` файлов из примонтированной папки, генерирует QR-код
на выбранный файл и отдаёт файл по HTTP так, чтобы его гарантированно смогла
скачать 3DS — даже если в имени файла есть символы вроде `™`, `®`, диакритика
и т.п., которые ломают закачку через стандартный FBI Remote Install.

## Как это работает

- Ссылка для скачивания никогда не содержит "сырое" имя файла — только
  внутренний ID и уже безопасное (ASCII) имя с расширением `.cia`. Поэтому
  спецсимволы в оригинальном имени никогда не попадают в URL и не ломают
  закачку на 3DS.
- Если имя файла содержит проблемные символы, в списке появляется пометка
  ⚠ и кнопка **«Исправить имя»**, которая физически переименовывает файл в
  хранилище на диске в безопасный вариант (полезно для порядка в библиотеке,
  не только для самой закачки).
- Список файлов сканируется заново при каждом открытии страницы — просто
  скопируй файл в примонтированную папку и обнови страницу в браузере.

## Запуск

1. Отредактируй `docker-compose.yml`: укажи в `volumes` реальный путь к
   папке с `.cia` файлами вместо `./cia`.
2. Запусти:
   ```
   docker compose up -d
   ```
3. Открой `http://<IP-сервера>:8000/` в браузере на любом устройстве в той
   же сети.
4. Выбери файл → **QR-код** → на 3DS в FBI: **Remote Install → Scan QR Code**
   → наведи камеру на код на экране.

## Переменные окружения

| Переменная | По умолчанию | Описание                                   |
|------------|--------------|---------------------------------------------|
| `CIA_DIR`  | `/cia`       | Путь внутри контейнера, где лежат .cia файлы |
| `PORT`     | `8000`       | Порт, на котором слушает веб-сервер          |

Готовый образ: [`sloth62/fbi-cia-web`](https://hub.docker.com/r/sloth62/fbi-cia-web).

## Сборка из исходников

```
docker build -t sloth62/fbi-cia-web:latest .
docker push sloth62/fbi-cia-web:latest
```
